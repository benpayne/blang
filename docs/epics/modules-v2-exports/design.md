# Design: modules-v2-exports

**Epic**: [overview.md](overview.md)

The binding design decisions are D1–D17 in the shared design record
([../modules-v2/overview.md](../modules-v2/overview.md)). This file adds the
epic-local context and contracts; it does not restate the record.

## Context

Plan-time recon (verified against master @ `7e75352`; every cite re-checked by
the 2026-08-04 review):

- **Construction is caller-allocating.** At a `Counter(5)` site the
  consumer's codegen computes `DataLayout::getTypeAllocSize`
  (`CGStruct.cpp:641-642`), generates the destructor from the field list via
  `getOrGenStructDestructor` (`CGStruct.cpp:660`), calls
  `__blang_rc_alloc_dtor(size, dtor)` (`CGStruct.cpp:663`), then
  `StructName_init` (`CGStruct.cpp:667-669`). Release goes through
  `__blang_rc_release`, which invokes the dtor pointer stored at allocation
  (`runtime/blang_runtime.c:77-83` stores `hdr->destructor`;
  `:115-131` invokes it at refcount zero) — the release path is already
  layout-free, **verified**. This asymmetry is what makes the factory ABI
  (U1) sufficient with zero runtime API change.
- **`.bmod` emission**: `BmodEmitter.cpp` emits full field layout and *no*
  methods for non-generic structs; generic structs ship an impl block with
  bodies (`BmodEmitter.cpp:238-261`). Protocol definitions are emitted
  (`BmodEmitter.cpp:302+`) but no conformance records.
- **`impl` parsing**: `QImplBlock.cpp` accepts only `fn`/`init`/`static fn`
  (line 125) — no `pub` token anywhere in impl blocks; `init` has duplicate
  detection (`QImplBlock.cpp:109-119`).
- **Data-contract codegen runs consumer-side**: `Sema::checkTableField`
  validates `.field` against `StructDefinition::getFields()`
  (`Sema.cpp:581` region); `SQLGen.cpp:277` reads field order for SQL;
  `@json` functions are generated by whichever module compiles the call
  (`CGRuntime.cpp:1519-1651`) and are called by name in real code
  (`examples/todo_app/main.b:160`).
- **Combine mode has two scope shapes**: namespaced stdlib modules (`net`,
  `fs`, `timer`, ...) each get their own `Scope` (`qcc.cpp:315-322`) — a
  boundary Sema can enforce against; the promoted `buffer`/`collections`/
  `cli` are parsed **into the user's own scope** (`qcc.cpp:308-313`) — no
  boundary exists until Epic B. `Map` has no `init`; its only construction
  form is the struct literal (`examples/wordfreq/main.b:27,86` + ≥6 codegen
  goldens).
- **Generic `.bmod` retention is a third category** (neither D15 metadata
  nor ABI residue): generic structs ship full field lists and **all** method
  bodies verbatim (`BmodEmitter.cpp:230-265`) because consumers
  monomorphize, and pub methods call private helpers
  (`stdlib/collections.b:85` `Map.set` → `find_slot`/`rehash` at `:87`/
  `:99`). Emission filtering must never apply to generics.
- **Build cache**: `BuildCache::computeKey` (`BuildCache.cpp:121-143`) hashes
  source + `blang.toml` + dep hashes only — no format version.
- **Resolution is a flat merge** (`qcc.cpp:324-381`) — out of scope here;
  Epic B's seam. This epic changes *what* is emitted/enforced, not *how*
  names resolve.
- **stdlib DTOs are field-consumed**: `HttpRequest` (`stdlib/net.b:190-194`),
  `HttpRequestLine`, `HttpParsedHeaders`, `FileInfo`; consumers reach in
  (`examples/todo_app/main.b:146-147`).

## Architecture

Component-level shape of the change:

```text
                 defining module (lib)                 consumer module (bin)
                ───────────────────────               ──────────────────────
 source ──▶ Sema: P9 export checks (U3)          Sema: field/literal
            visibility: pub members (U3)          visibility errors (U5),
                 │                                D15 metadata reads (U5)
                 ▼                                     ▲
            CodeGen: factory emission (U1)             │ resolves via .bmod
            StructName_new = alloc+dtor+init           │
                 │                                     │
                 ▼                                     │
            BmodEmitter (U2/U5):  ────────────▶  .bmod: pub signatures,
              pub methods/init/factory decls,          factory decls,
              conformance records (D16),               conformance records,
              enum variants (D17),                     [meta] section
              [meta] field section (D15),
              format version ──▶ BuildCache salt (U2)
```

## Interfaces & contracts

- **Factory ABI (U1)**: for every non-generic exported struct with a `pub
  init`, the defining module emits a factory symbol wrapping
  `__blang_rc_alloc_dtor(size, dtor)` + init; its C-level signature mirrors
  the init's parameters and returns the struct pointer. Consumers never
  compute a foreign struct's size or dtor. Release remains
  `__blang_rc_release` — no runtime API change.
- **`.bmod` format (U2/U5)**: carries a format-version marker; exported
  names, `pub` method/`init`/factory signatures, protocol-conformance
  records, enum variants+payloads; a compiler-facing metadata section for
  `table`/`@json` structs (D15). Field metadata in that section is **never
  resolvable from user source** — visibility is a resolution rule.
  **Generic structs are exempt from emission filtering**: full field layout
  and ALL method bodies (pub and private) keep shipping verbatim —
  monomorphization requires them; visibility for generic types is enforced
  purely in Sema. `BuildCache::computeKey` incorporates the format version.
- **Visibility invariants (U3/U5)**: fields — always module-private; struct
  literals — module-private; methods/`init` — private unless `pub`;
  violations are single located `file:line:col: error:` diagnostics through
  the existing `DiagnosticEngine`, in **both** build modes (Sema, never
  LLVM-gated). Same rules under `--combine` as under `.bmod` consumption
  **for namespaced stdlib modules**; the combine-promoted
  `buffer`/`collections`/`cli` are exempt this epic (no boundary exists —
  Known Issues entry per Principle VI; Epic B closes it).
- **P9 (U3)**: exported signatures may only reference exported types
  (functions, methods, enum variant payloads); violation errors at the
  library build, located at the offending declaration.

## Key decisions (epic-local; D1–D17 govern above these)

| # | Decision | Rationale | Alternatives rejected |
|---|----------|-----------|----------------------|
| A1 | Cross-module construction via library-emitted factory; same-module construction may keep the inline path | Release path is already layout-free (dtor stored at alloc); factory is the minimal ABI change closing F1 | Layout-in-`.bmod` as ABI metadata (forfeits rebuild win + weakens opacity); opaque handles/vtables (upheaval the record avoids) |
| A2 | The `.bmod` format-version salt lands in U2, the first format change | Warm caches would otherwise serve stale-format `.bmod`s mid-epic (F6 verified) | Deferring to epic end (guarantees mid-epic mystery failures) |
| A3 | U2 ships all methods (interim), U3 flips to private-by-default | `pub` doesn't parse in impl blocks yet; two small PRs beat one giant one; hole is documented | Single combined U2+U3 (larger, riskier review) |
| A4 | stdlib accessor surface is hand-designed per type (U4), design-audited before implementation | The DTO→opaque conversion is public-API design (F8); generated accessors are a record-level non-goal | Mechanical field→getter generation (banned); leaving stdlib field-transparent (breaks uniformity U5 needs) |
| A5 | D15 metadata is emitted only for `table`/`@json` structs (plus any ABI residue U1 cannot eliminate — target: none) | Un-annotated structs get the full rebuild-avoidance win; annotated shapes are already public contracts | Metadata for all structs (gives up the interface-hash win everywhere) |
| A6 | Generic structs exempt from emission filtering; the factory ABI applies only to non-generic structs; visibility for generics is Sema-only | Consumers monomorphize from `.bmod`-shipped layout+bodies (incl. private helpers); a library cannot pre-emit factories for an unbounded instantiation set | Filtering generic emission (breaks cross-module generics); generic factories (incoherent) |
| A7 | Combine-promoted `buffer`/`collections`/`cli` exempt from module-private enforcement this epic; `Map`/`Set` gain `pub init` in U4 | They parse into the user's own scope — no boundary exists until Epic B; `Map`'s only construction form today is the literal U5 outlaws | De-promoting them now (reintroduces the string-ARC double-free Epic B fixes); leaving `Map` literal-only (breaks under U5) |

## Invariants — must not break

- All existing gates: `./run_tests.sh`, `./test_codegen.sh` (both build
  modes), `--leak-check`, `./test_lsp.sh`, `test_build/run_build_tests.sh`,
  `ctest` runtime units, CI jobs per `docs/ci.md`.
- Same-module behavior of existing programs that don't cross module
  boundaries: parse, semantics, and codegen unchanged (except the new `pub`
  member syntax being *accepted*).
- Cross-module generics keep working (bodies in `.bmod`, `linkonce_odr`
  instances) — U1's spike explicitly covers one generic case.
- ARC/ownership semantics unchanged; runtime library APIs unchanged (the
  factory composes existing `__blang_rc_alloc_dtor`/`__blang_rc_release`).
- Diagnostics remain single located `file:line:col: error:` lines; quiet
  clean compiles (Principle III).
- The flat-merge resolution path in `qcc.cpp` is not modified (Epic B).
