# U2 security self-review (constitution Quality Gate 7: untrusted input)

This is input for the independent security review (evaluation.md: U2 security review). The untrusted inputs are the `initializationOptions.stdlibPath` value, the `BLANG_STDLIB_DIR` value, and the contents of the files in the selected directory.

- [x] **Path use is confined to read-only checks.** The selected path is used only as a prefix for `stat` and `access` (`lsp/StdlibLocation.cpp:33-34`, `:42`). It is also used as the directory of the read-only stdlib inputs that `ProjectCompile::run` lexes (`lsp/Compile.cpp:107`, via `BlangStdlib::selectStdlibFiles`). Nothing under it is written or executed.
- [x] **No traversal through names.** Every name appended to the path is either a fixed base name (`BlangStdlib::baseModuleNames()`) or an import identifier from `BlangStdlib::scanImports`. Those identifiers are the `isalnum || '_'` run (`StdlibSelect.cpp:43`), so no `/`, `.`, `..` or absolute component can be introduced.
- [x] **No execution, no network.** `sh tools/check_no_subprocess.sh build/blangd` prints `no-subprocess: OK`. The `blangd_no_subprocess` ctest passes in all three trees, and its teeth leg still catches `bcc`. Discovery adds only `stat`, `access`, `getenv` and `readlink` (`StdlibSelect.cpp` `executableDir`).
- [x] **Malformed configuration never crashes.** `Json::get` is null-safe on non-objects (`lsp/Json.cpp:38-47`), and only a string `stdlibPath` is accepted (`lsp/Server.cpp:145`). I verified this under the ASan blangd with `initializationOptions` set to `"garbage"`, to `{"stdlibPath": 42}`, to `{"stdlibPath": ["x"]}` and to `null`. In every case the value is treated as unset, there is no crash, and the session exits 0.
- [x] **Symlinks are followed read-only, as `bcc` does.** I verified this with `stdlibPath` pointing at a symlink to `stdlib/`; the document is clean.
- [x] **Hostile file contents** in a configured directory are handled exactly as `qcc` handles them. They produce located lexer and parser diagnostics, which are filtered from the document's publish (C5). Memory is bounded per reparse (`parser_no_leak` 50-reparse loop) and freed with the result.
- [x] **An unusable selected route never falls through.** This is a deliberate safety property: blangd never silently uses a stdlib other than the one the user configured (`stdlib_locate` (b); goldens `stdlib_missing_env`, `stdlib_missing`).
